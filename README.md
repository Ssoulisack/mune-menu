# Mune — QR menu

Single-restaurant digital menu. Customers scan a QR code and see the menu at `/`; staff manage it at `/admin`.
Runs entirely on Cloudflare's free tier: **Workers** (Hono API + React app), **D1** (SQLite), **KV or R2** (photos), **Access** (admin login).

## Local development

Requires Node 22.12+ (`nvm use`).

```bash
npm install
npm run db:migrate:local   # create tables in the local D1
npm run db:seed:local      # optional sample menu
npm run dev                # http://localhost:5173  and  http://localhost:5173/admin
```

`.dev.vars` (copied from `.dev.vars.example`) sets `DEV_SKIP_AUTH=true` so `/admin` works locally without Cloudflare Access.

Changing the schema: edit `src/worker/db/schema.ts`, then `npm run db:generate` and `npm run db:migrate:local`.

## Deploy (one-time setup)

1. **Domain on Cloudflare** — add your domain at dash.cloudflare.com (Free plan) and switch the nameservers at your registrar.
2. **Login**: `npx wrangler login`
3. **Database**: `npx wrangler d1 create mune-db` → paste the `database_id` into `wrangler.jsonc`.
4. **Photo storage** — pick one:
   - KV (no card needed): `npx wrangler kv namespace create IMAGES_KV` → paste the `id` into `wrangler.jsonc`.
   - R2 (10 GB free, needs a card on file): `npx wrangler r2 bucket create mune-images`, then replace the `kv_namespaces` block with
     `"r2_buckets": [{ "binding": "IMAGES_R2", "bucket_name": "mune-images" }]`.
5. **Custom domain** — uncomment `routes` in `wrangler.jsonc` and set `menu.yourdomain.com`.
6. **Migrate + deploy**:
   ```bash
   npm run db:migrate:remote
   npm run deploy
   ```
7. **Protect the backoffice with Cloudflare Access** (Zero Trust → free for 50 users):
   - Zero Trust dashboard → *Access → Applications → Add → Self-hosted*.
   - Domain `menu.yourdomain.com`, paths `admin` **and** `api/admin` (add both).
   - Policy: *Allow* → *Emails* → your staff emails. Login method: One-time PIN.
   - Copy the **Application Audience (AUD) tag** and your team domain (`<team>.cloudflareaccess.com`) into `vars.ACCESS_AUD` / `vars.ACCESS_TEAM_DOMAIN` in `wrangler.jsonc`, then `npm run deploy` again.
   - Optional: disable the `*.workers.dev` URL (`"workers_dev": false`) so the only entry point is your domain.
8. Open `/admin/qr`, set the link to `https://menu.yourdomain.com/`, download or print the table card.

The worker verifies the Access JWT on every `/api/admin/*` request, so the admin API is closed even if Access is misconfigured (it returns 500/401 instead of being open).

## Layout

```
src/worker/        Hono API (Cloudflare Worker)
  db/schema.ts     Drizzle tables: settings, categories, items
  routes/public.ts GET /api/public/menu (edge-cached), GET /img/*
  routes/admin.ts  CRUD under /api/admin (Access-protected)
src/web/           React app — pages/Menu.tsx (public), pages/admin/* (backoffice)
src/shared/        Types shared by both
migrations/        SQL migrations (drizzle-kit)
seed/seed.sql      Sample data
```

Prices are stored as integers in the currency's minor unit (whole kip for LAK, cents for USD). Changing the currency in settings doesn't convert existing prices.

## Languages

Enable languages under **Settings**. Text typed in the main fields is in the *main language*; every other enabled
language gets its own translation fields (items, categories, restaurant info, theme banner). Missing translations fall
back to the main text, and the backoffice flags them with a "needs translation" badge. Customers get a language switcher;
the first visit picks their phone's language when it's enabled.

## Themes & seasons

**Themes** in the backoffice: a default theme plus seasons (e.g. Pi Mai Lao 13–16 Apr) that switch on automatically every
year in the restaurant's timezone. Each theme starts from a preset and can be customised (colours, header gradient/photo,
falling decorations, font, corners, banner message) with a live phone preview.

The sample data is generated by `python3 scripts/build-seed.py` → `seed/seed.sql`.
